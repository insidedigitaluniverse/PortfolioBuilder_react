Portfolio Builder - How to make it yours

This guide shows every change you need to make to turn this template into your own portfolio: which file to open, what to change, and how to run and publish it. You only need to edit text. No coding knowledge is needed.

1. Set up and run the project

  1. Install Node.js (the LTS version).
  2. Download the project and install its packages: 
    git clone https://github.com/insidedigitaluniverse/PortfolioBuilder_react.git
cd PortfolioBuilder_react
npm install
  3. Start the project: 
    npm run dev
  4. Open the link shown in the terminal (usually http://localhost:5173). Keep it open. Every time you save a file, the page updates by itself.

2. Which files you will change

File / folder What it is for Must change?
src/data/portfolio.js All your content: name, photo, links, skills, projects, education, colours. This is the main file. Yes
public/ Your files: photo, logo, resume PDF and project images. Yes (your photo)
index.html Browser tab icon and the description shown in Google search. Optional
public/favicon.svg The small icon in the browser tab. Optional
src/styles/global.css Design and colours. Only for advanced changes. No
src/components/ The code of each section. You do not need to touch it. No

Tip: in portfolio.js, change only the text inside the quotes '...'. Keep the commas, brackets and quotes as they are. If the page goes blank after a change, look for a missing comma or quote near the line you just edited.

3. Your basic details

Open src/data/portfolio.js and change these lines at the top:

Field What to put Example
name Your full name. Shown in the hero, menu bar, footer and browser tab. 'Riya Sharma'
initials 2 letters. Shown in the menu bar only when logo is empty. 'RS'
roles 2 to 4 short lines that type one after another in the hero. The first one is also used in the browser tab title. ['B.Com Student', 'Content Writer']
tagline One sentence about you, shown under your name. 'I enjoy writing and solving business problems.'
location Your city and country. 'Pune, India'
email Your email. The Contact section and the email icon in the hero use it. If it is empty, the Contact section is hidden. 'riya@example.com'
phone Your phone number. Leave '' to hide it. ''
resumeUrl Put your resume.pdf in public/ and set the path here to show a Resume button. Leave '' to show a "Contact me" button instead. '/resume.pdf'
availableText Small badge in the hero. Leave '' to hide it. 'Open to internships'
highlights Up to 6 short words shown floating around your photo. ['Excel', 'Tally', 'Writing']

4. Your photo and logo

The template comes with the InsideDigitalUniverse logo as the photo and the menu bar logo. Replace both with your own.

  1. Copy your photo into the public/ folder, e.g. public/me.jpg. A square photo works best (for example 720 x 720 pixels). It is shown inside a circle.
  2. In portfolio.js, change the photo line: 
    photo: '/me.jpg',
  3. Menu bar logo (the small round image at the top left, also in the mobile menu). Choose one:
    • Your own small logo: put it in public/ (a small square image, e.g. 96 x 96) and set logo: '/my-logo.png',
    • Your initials instead of an image: set logo: '', and the 2 letters from initials are shown.
  4. You can delete the template images you no longer use: public/idu-logo.png, public/idu-logo-small.png and public/profile.svg.

The path always starts with / and does not include the word public. For example public/me.jpg becomes '/me.jpg'.

5. Social links

In portfolio.js, find socials and put your full profile links. Leave a link as '' to hide its icon.

socials: {
  linkedin: 'https://www.linkedin.com/in/your-username',
  github: 'https://github.com/your-username',
  instagram: '',
  twitter: '',
  youtube: '',
  behance: '',
  website: '',
},

These icons are shown in the hero, the Contact section and the mobile menu.

6. Section names and headings

In portfolio.js, the sections part sets the text of each section:

  • menu - the name in the top menu.
  • eyebrow - the small label above the heading.
  • title - the big heading of the section.
  • subtitle - a short line under the heading (only Projects and Contact have it).

Example: to call "Experience" "Work" instead:

experience: { menu: 'Work', eyebrow: 'Work', title: 'Where I have worked' },

7. Your content

All of these are in portfolio.js. To add an item, copy an existing block { ... }, and change its text. To remove one, delete its whole block.

About

about is a list of paragraphs. Write 1 to 3 short paragraphs about yourself.

about: [
  'I am a final year B.Com student who loves numbers and writing.',
  'I am looking for an internship in finance or marketing.',
],

Stats

stats are the numbers shown in the About section. They count up when the visitor scrolls to them.

stats: [
  { value: '5+', label: 'Projects' },
  { value: '3', label: 'Certificates' },
],

Skills

Each group has an icon (any emoji), a title and a list of items. All skill items are also shown in the moving strip under the hero.

{ icon: '🛠️', title: 'Tools', items: ['MS Excel', 'Tally', 'Canva'] },

Experience

Internships, jobs, volunteering or club work. points is a list of what you did.

{
  role: 'Marketing Intern',
  company: 'ABC Pvt Ltd',
  period: 'May 2025 - Jul 2025',
  points: ['Made social media posts for 3 products.', 'Wrote a weekly sales report.'],
},

Projects

Field What to put
title, description Project name and one or two lines about it.
tags Short words, e.g. ['Excel', 'Research'].
category A group name, e.g. 'Academic' or 'Personal'. Filter buttons are made from these names automatically.
image Put an image in public/projects/ and set e.g. '/projects/survey.png'. Leave '' for no image.
links Any number of buttons, e.g. [{ label: 'View report', url: 'https://...' }]. Use [] for no links. 
{
  title: 'Market Survey Report',
  description: 'A survey of 200 people with charts and a short report.',
  tags: ['Excel', 'Analysis'],
  category: 'Academic',
  image: '/projects/survey.png',
  links: [{ label: 'Read report', url: 'https://drive.google.com/...' }],
},

Achievements

Awards and certificates. url can link to the certificate (leave '' if you have none).

{ title: 'Excel for Beginners', issuer: 'Coursera', year: '2024', url: 'https://...' },

Education

{
  degree: 'B.Com',
  school: 'XYZ College, Pune',
  period: '2022 - 2025',
  details: 'Accounting and Finance. CGPA 8.5',
},

8. Hide a section you do not need

Set its list to an empty list []. The section and its menu link disappear by themselves.

experience: [],
achievements: [],

This works for about, skills, experience, projects, achievements and education. The Contact section is hidden when email is ''.

9. Colour and theme

  • accentColor - the main highlight colour (buttons, links, the photo ring). Use any hex colour, e.g. '#f97316' for orange or '#22c55e' for green.
  • defaultTheme - 'dark' or 'light'. This is the theme a new visitor sees first. Visitors can still switch with the theme button, and their choice is remembered.

If you changed the theme and do not see it, your browser remembers your last choice. Click the theme button or open the page in a private window.

10. Browser tab title, icon and description

  • Tab title: made automatically from name and the first roles item, e.g. "Riya Sharma | B.Com Student". Nothing to change.
  • Tab icon: replace public/favicon.svg with your own icon. If your icon is a PNG, put it in public/ and change this line in index.html: 
    <link rel="icon" type="image/png" href="/my-icon.png" />
  • Search description: in index.html, change the text of <meta name="description" content="..."> to one line about you. Google may show it in search results.

11. Build and publish online

  1. Check the final version on your computer: 
    npm run build
npm run preview
  2. Create a free GitHub account and push the project to a new repository.
  3. Sign in to Vercel with GitHub, click Add New > Project, import your repository and click Deploy. The default settings (framework Vite, output folder dist) work as they are.
  4. Vercel gives you a free link like your-name.vercel.app. Every time you push a change to GitHub, the site updates by itself.

12. Final checklist

  • Name, initials, roles and tagline changed.
  • Your photo in public/ and photo updated.
  • Menu bar logo changed to your logo, or logo: '' to show your initials.
  • Email, location and phone (or '') are correct.
  • Social links point to your own profiles. Unused ones are ''.
  • All sample text replaced: about, stats, skills, experience, projects, achievements, education.
  • Sections you do not need set to [].
  • Resume PDF added (optional).
  • Accent colour and default theme chosen.
  • Favicon and search description updated (optional).
  • npm run build works without errors.
