# Contributing to Portfolio Builder

Thanks for your interest in improving Portfolio Builder!

## Reporting bugs

Open an issue on GitHub with:

- A clear title.
- Steps to reproduce the problem.
- Your browser and operating system.

## Contributing code

1. Fork the repository and clone your fork.
2. Create a branch: `git checkout -b your-feature-name`.
3. Run `npm install` and `npm run dev`, make your changes and test them on desktop and mobile.
4. Run `npm run build` to make sure the build passes.
5. Commit, push your branch and open a pull request against `main`.

## Guidelines

- Keep all user content in `src/data/portfolio.js`, so the template stays easy to customise.
- Use plain CSS and the existing CSS variables for colors.
- Keep the page responsive and accessible (labels, alt text, keyboard focus).
